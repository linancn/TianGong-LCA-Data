# 天工 LCA 数据库

[English](README.md)

> **维护说明**
>
> 本仓库作为历史快照保留，自 2026 年 6 月 21 日起不再维护，也不再通过 GitHub Release 发布下载文件。如需获取最新的天工 LCA 数据，请访问 [天工 LCA 平台](https://lca.tiangong.earth/)，打开所需数据集后使用平台中的 **Export** 按钮导出。

欢迎访问 **天工 LCA 数据库**的历史仓库。天工 LCA 数据库由行业专家社区共同建设，汇集了中国本土单元过程数据，并将其作为开放参考数据集提供使用。

- **开放免费**：我们的数据库面向所有用户开放并免费使用，推动可持续发展数据的普惠化，促进全球协作与创新。
- **可追溯、可信赖**：数据库以透明性和可靠性为基础，确保每一条数据都经过严谨核验并清晰标注来源，为准确评估提供可信信息。
- **历史快照**：本仓库保存了天工 LCA 数据的公开历史快照。当前数据更新和导出请通过天工 LCA 平台完成。

为便于用户理解并使用天工 LCA 数据开展生命周期评价，本仓库继续作为历史参考资料保留。如需使用当前有效的数据集，请通过平台导出流程获取。

此外，我们建立了国际通用的生命周期数据共享节点 Soda4LCA，具备与联合国全球 LCA 数据访问网络 Global LCA Data Access (GLAD)、欧盟生命周期数据网络 Life Cycle Data Network (LCDN) 等国际数据平台对接的技术基础。更多信息请访问：[天工 Soda4LCA 数据节点](https://lcadata.tiangong.world)。

### 导出当前数据

1. 打开[天工 LCA 平台](https://lca.tiangong.earth/)。
2. 查找并打开所需的数据集。
3. 点击平台中的 **Export** 按钮。
4. 根据平台提供的导出选项完成选择，并下载生成的文件。
5. 将导出的文件用于你的 LCA 软件或数据工作流。

### 使用导出数据

- 在导入 LCA 工作流前，请先从[天工 LCA 平台](https://lca.tiangong.earth/)导出当前数据集。
- 请根据项目需求和平台提供的导出选项，选择合适的数据格式和后续使用的软件。
- 具体软件的导入步骤，请参考你所使用的 LCA 工具或数据工作流文档。
